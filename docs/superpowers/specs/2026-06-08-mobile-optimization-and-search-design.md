# 디자인 명세서: 서울형 키즈카페 모바일 최적화 및 조회 기능 도입

본 문서는 서울형 키즈카페 실시간 예약 모니터링 대시보드의 모바일 최적화 및 단발성 "조회" 기능, 지점 검색 기능 추가에 대한 디자인과 설계 사양을 정의합니다.

---

## 1. 개요 및 목표
* **목표**: 스마트폰 등 모바일 디바이스에서 100% 쾌적하게 동작하는 UI/UX 구현 및 시인성 극대화.
* **주요 변경 사항**:
  1. 가독성이 강화된 프리미엄 다크 테마 적용.
  2. 모바일 반응형 레이아웃 (사이드바 슬라이딩 드로어 및 테이블 Sticky 고정 열).
  3. 실시간 단발성 **조회** 기능 (알림음 없는 즉시 검색) 추가.
  4. 사이드바 내 키즈카페 명 텍스트 검색 기능 추가.

---

## 2. 세부 디자인 및 레이아웃 설계

### A. 프리미엄 다크 테마 (가독성 보정)
어두컴컴하고 답답한 느낌을 배제하고, 시인성을 높이기 위한 색상 대비를 강화합니다.
* **배경 및 영역**:
  * 메인 배경 (`--bg-primary`): `#080c14` (정밀한 딥 미드나잇)
  * 컴포넌트 배경 (`--bg-secondary`): `#111827` (다크 네이비 그레이)
  * 테이블 셀 및 카드 배경 (`--bg-card`): `#1f2937` (슬레이트 그레이)
  * 보더 색상 (`--border-color`): `#374151` (선명한 경계 구분)
* **텍스트 가독성**:
  * 기본 텍스트 (`--text-primary`): `#ffffff` (완전한 화이트로 대비 최대화)
  * 보조 텍스트 (`--text-muted`): `#9ca3af` (시인성이 우수한 은회색)
* **공석 상태 강조 (`--accent`)**:
  * 공석이 있는 경우: 경계선 `#10b981`, 백라이트 글로우 `rgba(16, 185, 129, 0.25)` 적용하여 눈에 띄게 구성.
  * 공석이 없는 경우: 배경 투명도 조정으로 비활성화 느낌 강조.

### B. 모바일 반응형 레이아웃 (가로 768px 이하)
* **헤더 컴팩트 레이아웃**:
  * 모바일 화면 폭에 맞춰 헤더의 컨트롤 요소들을 효율적으로 정렬.
  * 불필요하게 긴 레이블 텍스트는 간소화하거나 아이콘화.
* **사이드바 드로어(Drawer) 및 오버레이**:
  * 모바일에서 `#sidebar`는 `position: fixed; left: -100%; width: 280px; height: 100vh;` 상태로 은닉.
  * `🔍 지역/지점 선택` 버튼 클릭 시 `left: 0`으로 슬라이딩 인.
  * `#sidebar-overlay`를 통해 본문 영역 터치를 방지하고, 오버레이 클릭 시 드로어를 닫음.
  * **모바일 자동 닫힘**: 지점 체크박스 선택 시, 모바일 해상도일 경우 0.5초 대기 후 자동으로 드로어가 닫혀 즉시 예약 표가 보이게 UX 제어.
* **스티키(Sticky) 테이블 레이아웃**:
  * `.matrix-wrapper` 영역에 가로 스크롤 (`overflow-x: auto`) 적용.
  * 테이블의 첫 번째 열(`th:first-child`, `td:first-child`)인 **"키즈카페 명"**을 `position: sticky; left: 0`으로 고정. 가로 스크롤 중에도 지점명이 화면 왼쪽 끝에 항상 노출되도록 보장.

### C. 기능 추가: "조회" 버튼 및 키즈카페 검색창
1. **"조회" 버튼 (단발성 검색)**:
   * 헤더 컨트롤에 `⚡ 조회` 버튼을 나란히 배치.
   * 모니터링 주기 루프와는 별개로, 클릭 시 즉시 선택된 지점들의 `/api/scrape` 백엔드 API를 호출해 데이터를 최신화. (알림음 차단)
2. **사이드바 내 지점 검색창 (Search Input)**:
   * 자치구 목록 상단에 `<input type="text" id="cafe-search" placeholder="🔍 키즈카페 검색...">` 입력란 추가.
   * 사용자가 입력한 단어가 포함된 키즈카페만 목록에 실시간 필터링. 검색어가 일치하는 키즈카페가 있는 자치구 아코디언은 자동으로 펼침 상태로 유도하여 사용 편의 증대.

## 3. 검증 계획 (Verification Plan)

### A. 수동 검증 (Manual Verification)
1. **모바일 뷰포트 에뮬레이션**:
   * Chrome DevTools 또는 브라우저 에뮬레이터의 Responsive 모드(iPhone 12 Pro, 390px 등)로 화면 가로 폭을 줄여 검증.
   * 사이드바 드로어가 정상 작동하고, 배경 오버레이 터치 시 닫히는지 확인.
   * 지점 선택 후 드로어가 자동 Close 되는지 동작 확인.
2. **테이블 가로 스크롤 및 Sticky 테스트**:
   * 모바일 뷰에서 표를 우측으로 끝까지 스크롤한 뒤, 첫 번째 컬럼(키즈카페 명)이 좌측에 정상 고정되어 있는지 검증.
3. **조회 및 검색 기능 검증**:
   * "조회" 버튼 클릭 시, 모니터링 상태가 비활성이더라도 실시간 현황이 테이블에 정상 업데이트되는지 확인.
   * 사이드바 검색창에 글자 입력 시 키즈카페명이 알맞게 필터링되는지 검증.
