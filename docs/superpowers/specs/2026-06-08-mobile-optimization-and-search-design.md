# 디자인 명세서: 서울형 키즈카페 모바일 최적화 및 시간대별 조회 비교 기능 도입

본 문서는 서울형 키즈카페 실시간 예약 모니터링 대시보드의 모바일 최적화, 단발성 "조회" 기능, 지점 검색 기능 및 **시간대별 1:1 비교 대시보드 테이블 레이아웃** 구현에 대한 설계 사양을 정의합니다.

---

## 1. 개요 및 목표
* **목표**: 스마트폰 등 모바일 디바이스에서 100% 쾌적하게 동작하는 UI/UX 구현 및 여러 지점의 예약 상황을 동일 날짜 시간대별로 한눈에 비교할 수 있는 대시보드 구현.
* **주요 변경 사항**:
  1. 가독성이 강화된 프리미엄 다크 테마 적용.
  2. 모바일 반응형 레이아웃 (사이드바 슬라이딩 드로어 및 테이블 가로 스크롤).
  3. 실시간 단발성 **조회** 기능 (알림음 없는 즉시 검색) 추가.
  4. 사이드바 내 키즈카페 명 텍스트 검색 기능 추가.
  5. **대시보드 테이블 레이아웃 전면 개편**:
     * 기준 날짜 선택형 비교 테이블.
     * 가로축(열 Header): 선택된 키즈카페 명 (구명 제거 및 간소화한 명칭).
     * 세로축(행 Header): 선택된 모든 지점이 해당 날짜에 운영하는 실제 모든 고유 시간대 목록.
     * 기본 날짜 자동 지정: 오늘 기준 가장 가까운 토요일/일요일 날짜로 초기값 지정.

---

## 2. 세부 디자인 및 레이아웃 설계

### A. 프리미엄 다크 테마 (가독성 보정)
* **배경 및 영역**:
  * 메인 배경 (`--bg-primary`): `#080c14`
  * 컴포넌트 배경 (`--bg-secondary`): `#111827`
  * 테이블 셀 및 카드 배경 (`--bg-card`): `#1f2937`
  * 보더 색상 (`--border-color`): `#374151`
* **텍스트 가독성**:
  * 기본 텍스트 (`--text-primary`): `#ffffff`
  * 보조 텍스트 (`--text-muted`): `#9ca3af`
* **공석 상태 강조 (`--accent`)**:
  * 공석이 있는 경우: 경계선 `#10b981`, 백라이트 글로우 `rgba(16, 185, 129, 0.25)` 적용.
  * 공석이 없는 경우: 배경 투명도 조정으로 비활성화 느낌 강조.

### B. 모바일 반응형 레이아웃 (가로 768px 이하)
* **헤더 컴팩트 레이아웃**:
  * 모바일 화면 폭에 맞춰 헤더의 컨트롤 요소들을 효율적으로 정렬.
* **사이드바 드로어(Drawer) 및 오버레이**:
  * 모바일에서 `#sidebar`는 `position: fixed; left: -100%; width: 280px; height: 100vh;` 상태로 은닉.
  * `🔍 지역/지점 선택` 버튼 클릭 시 `left: 0`으로 슬라이딩 인.
  * **모바일 자동 닫힘**: 지점 체크박스 선택 시, 모바일 해상도일 경우 0.3초 대기 후 자동으로 드로어가 닫혀 즉시 예약 표가 보이게 UX 제어.
* **테이블 레이아웃**:
  * `.matrix-wrapper` 영역에 가로 스크롤 (`overflow-x: auto`) 적용.
  * 테이블의 첫 번째 열(`th:first-child`, `td:first-child`)인 **"시간대"**를 `position: sticky; left: 0`으로 고정하여 가로 스크롤 중에도 시간대가 항상 노출되도록 보장.

### C. 시간대별 대조 매트릭스 테이블 구조
1. **가로축(열 Header)**:
   * 선택한 키즈카페의 간소화된 이름이 나열됩니다.
   * **간소화 알고리즘 (`simplifyCafeName`)**:
     * `서울형 키즈카페 `, `시립 `, `OO구 ` 등을 제거하고 괄호 뒤의 추가 명칭도 삭제하여 콤팩트하게 변경.
     * 예: `서울형 키즈카페 용산구 청파동점` $\rightarrow$ `청파동점`
2. **세로축(행 Header)**:
   * 선택된 지점들의 해당 날짜 스케줄 데이터에서 모든 고유 시간대(`useBeginTime ~ useEndTime` 포맷)를 추출해 오름차순 정렬하여 행을 구성합니다.
   * 예: `09:30 ~ 11:30`, `13:00 ~ 15:00`, `15:30 ~ 17:30` 등
3. **기본 날짜 계산 (`getUpcomingWeekend`)**:
   * 페이지 첫 로드 혹은 날짜 미입력 시, 오늘 이후 가장 가까운 **토요일** 또는 **일요일** 날짜를 계산하여 날짜 인풋 `#filter-date` 의 기본값으로 설정합니다. 오늘이 이미 주말인 경우 오늘 날짜로 고정합니다.

### D. 기능 추가: "조회" 버튼 및 키즈카페 검색창
1. **"조회" 버튼 (단발성 검색)**:
   * 헤더 컨트롤에 `⚡ 조회` 버튼을 배치하여 수동 갱신 지원.
2. **사이드바 내 지점 검색창 (Search Input)**:
   * 자치구 목록 상단에 `<input type="text" id="cafe-search" placeholder="🔍 키즈카페 검색...">` 입력란 추가.
   * 입력된 단어가 포함된 키즈카페만 목록에 실시간 필터링.

## 3. 검증 계획 (Verification Plan)

### A. 수동 검증 (Manual Verification)
1. **가장 가까운 주말 자동 지정 검증**:
   * 페이지 진입 시 오늘 날짜 기준으로 가장 가까운 주말 날짜가 날짜 선택창에 기본 표시되는지 확인.
2. **지점명 축약 검증**:
   * 테이블이 그려질 때 "서울형 키즈카페 동작구 노량진2동점(동작키즈카페)" 등의 긴 이름이 "노량진2동점"과 같이 깔끔하게 축약되는지 검증.
3. **시간대별 1:1 비교 레이아웃 검증**:
   * 여러 지점(예: 청파동점, 노량진2동점)을 선택하고 조회를 눌렀을 때, 가로 헤더에 각 지점명이 노출되고 세로축에 운영 시간대가 독립된 행으로 구분되어 1:1 비교가 올바르게 수행되는지 확인.
